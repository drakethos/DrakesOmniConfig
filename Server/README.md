# DrakesOmniConfigServer

Server/admin build of [DrakesOmniConfig](../README.md): same engine, plus tools for building and testing modlets (planned: console commands, an HTML helper for constructing overrides without hand-writing YAML).

Standalone — do not install alongside `DrakesOmniConfig`. Install this one instead if you're the one authoring modlets for your server.
