# DrakesOmniConfig
The ultimate configuration tool for valheim. Inteligently exposes just about anything in the game to config and mod, and allows you to 
control it with your own mod pack. No need for several sepperate mods to tweak a few things.
What it does:
	allows you to change any field of just about anything ingame, Uses delta to prevent load slow down. 

	Later: Expose harmony patch points for visual / node based modding.

See [Server/README.md](Server/README.md) for the server/admin build (same engine, plus modlet-authoring tools) — standalone, don't install both.
